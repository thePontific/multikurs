# Распределённая система передачи снимков с микроскопа

Курсовая работа (МГТУ им. Н.Э. Баумана, ИУ5).

**Задание:** система для передачи снимков с микроскопа в реальном времени. Пользователь вводит имя, номер образца и увеличение (10×–1000×), получает изображения в чате в стиле Telegram. Эмулируется потеря 7% сегментов.

**Стек:** React, TypeScript, MUI, Redux Toolkit, Node.js, Express, WebSocket, Golang, Apache Kafka, MinIO.

**Архитектура:** три сервиса — прикладной (React + Node.js), транспортный (Golang + Kafka), агентный (Golang + MinIO).
